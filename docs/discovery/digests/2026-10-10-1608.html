Taking one node travelling: what running a sovereign AI stack on DGX Spark actually taught us | MarStack

A rare, high-signal infrastructure postmortem uncovering dangerous unified-memory failure modes when running Blackwell GB10 hardware in production.
  • Unified memory across Grace Blackwell lacks VRAM protection boundaries, allowing CPU weight-streaming memory pressure to trigger the OS OOM killer against active GPU ranks.
  • Losing one node in a tensor-parallel pair caused wedged head-node retries and complete cluster failure.
  • Establishes an operational invariant that unified-memory nodes cannot mix worker and standalone inference modes without strict hard transitions.
