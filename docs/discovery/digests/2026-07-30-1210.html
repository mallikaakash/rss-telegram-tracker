Detailed engineering write-up presenting an asymmetric KV cache compression scheme that solves linear scaling bottlenecks in multi-agent LLM inference.
  • Multi-agent LLM inference scales KV cache memory linearly, requiring ~19.8 GB of VRAM just for KV context across 15 agents on Llama-3-8B with a 7K token window.
  • PolyKV uses asymmetric KV cache compression to share a single cached representation among N agents, converting memory complexity from O(N) to O(1).
  • The approach achieves a 97.7% reduction in multi-agent KV memory footprint with under 1% loss in output quality.
