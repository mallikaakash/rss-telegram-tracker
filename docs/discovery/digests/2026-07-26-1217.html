Neural Scaling Universality: If Exponents Are Fixed, Time to Understand Coefficients - arXiv.gg

A paper proposing that neural scaling exponents are fixed by universal mechanisms, shifting the key to model optimization entirely to scaling coefficients.
  • Scaling law exponents are mathematically fixed by generic mechanisms: Softmax nonlinearity (1/3 time scaling), superposition (inverse width), and layer ensembling (inverse depth).
  • Because exponents are universal across current architectures, compute-optimal frontiers are dictated by architecture- and data-dependent coefficients.
  • Near-term LLM efficiency gains depend on understanding and tuning scaling coefficients rather than seeking different exponent slopes.

I Wrote a GPU Matmul Kernel From Scratch in Triton. Here's Everything I Learned

A detailed technical breakdown of GPU memory architecture bottlenecks and writing optimized matmul kernels step-by-step in Triton.
  • GPU matmul performance is constrained by HBM memory bandwidth (~2 TB/s) relative to fast on-chip SRAM (~19 TB/s) rather than raw FLOPS.
  • Block-tiling techniques minimize DRAM read latency by loading matrix blocks directly into SRAM for tensor cores.
  • Triton abstracts block-level thread management in Python while compiling to machine code competitive with PyTorch native matmul.
