TimeSeries Tiered Storage Journey: Kafka/Flink Streams to Native Cassandra Cold Reads

Exceptional distributed storage systems case study on migrating multi-petabyte time-series data to tiered S3 cold storage to optimize cost and latency.
  • Transitioned from a dual-write Kafka/Flink to S3 architecture toward reading historical data directly from Cassandra S3 backups via pluggable Memtables.
  • Leverages an immutable Time Slices partitioning model where write-frozen historical tables can safely be shifted to object storage.
  • Preserves sub-second read query latency and unified API semantics while eliminating high-density storage strain on active Cassandra clusters.

Masterclass in high-throughput distributed systems engineering, detailing how Netflix evolved its ad telemetry using stateful Flink streaming joins.
