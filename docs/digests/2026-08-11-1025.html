Show HN: Needle2: 14MB agentic LLM for phones, wearables, smart home and robots

Presents a novel 45M parameter ultra-compact LLM tailored specifically for edge tool calling, running within 28MB RAM.
  • Needle 2 uses 2-bit quantization (CQ2-bit) in a 14MB binary to achieve 500+ tok/s decode on Raspberry Pi 5.
  • Frames device control and extraction purely as schema mapping, outperforming larger models like FunctionGemma 270M on mobile benchmarks.
  • Open-sourced under Apache 2.0 with weights on Hugging Face and native/Wasm execution targets.

Rust SIMD on the GPU

High-quality engineering deep-dive on mapping Rust's portable SIMD abstractions directly to GPU SIMT warp lanes.
  • VectorWare maps core::simd's generic Simd type directly to 32-lane GPU warps, compiling arithmetic directly to GPU PTX instructions.
  • Enables cross-platform SIMD code in no_std Rust without relying on hardware-specific vendor intrinsics.
  • Completes a thread-to-warp and lane-to-SIMD parallel execution model for writing GPU kernel code in Rust.

Forking-Sequences — Part II: Multi-Horizon Forecast Ensembling with Reduced Volatility

Deep research post on multi-horizon time-series forecasting that reduces forecast volatility in pretrained foundation models at zero extra encoder compute.
  • Introduces Forking-Sequences forecast ensembling using overlapping predictions from a single forward pass.
  • Proposes two new volatility metrics (sFPC and EV) to penalize inaccurate revision size in real-time time-series forecasting.
  • Exponential smoothing cuts volatility by ~10% with under 0.1% accuracy cost across TSFMs like Chronos-2, TimesFM, and PatchTST.
