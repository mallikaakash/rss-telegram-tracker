Kimi Linear: An Expressive, Efficient Attention Architecture

Crucial deep-dive into a novel linear attention architecture that drastically cuts KV cache and boosts vLLM inference throughput.
  • Introduces Kimi Delta Attention (KDA), combining Gated DeltaNet with fine-grained gating and Diagonal-Plus-Low-Rank transition matrices.
  • Pretrains a 3B active / 48B total parameter hybrid model (KDA + MLA) that outperforms full attention across context lengths and RL regimes.
  • Reduces KV cache usage by 75% and achieves 6x decoding throughput on 1M contexts, open-sourcing custom kernels and vLLM code.

LFM2.5-Encoders for Fast Long-Context Inference on CPU

Directly relevant guide on adapting LLM decoder backbones into bidirectional encoders optimized for fast CPU inference.
  • Converts causal Liquid Foundation Models into bidirectional encoders using symmetric short convolutions and bidirectional attention masks.
  • Supports an 8,192-token context while running ~3.7x faster on CPU than ModernBERT-base.
  • Releases 230M and 350M models on Hugging Face with recipes for fine-tuning, intent routing, and classification.

DMARC Has Been Public Since 2012. 68.4% of Domains Still Don't Enforce It

Provides practical network infrastructure data on email security compliance and authentication policy gaps.
  • Analysis of 67,336 domains shows 68.4% fail to enforce DMARC policies.
  • Only 16.3% of domains actively enforce p=reject, while 23.3% remain stuck on monitor-only p=none.
  • The main bottleneck in moving to enforcement is lack of visibility into third-party outbound mail sources.
