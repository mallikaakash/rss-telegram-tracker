Must readCloudflare Blog

Introducing Clef-omni with full multimodality, plus a faster Clef and a cheaper Clef-flash

A stellar architectural deep-dive from Cloudflare detailing an MoE decision model that completely skips token generation for latency-critical multimodal scoring.
  • Built Clef-omni on top of Qwen3-Omni-30B-A3B-Instruct MoE, retaining multimodal comprehension while discarding the TTS generation components.
  • Eliminates token generation entirely: executes a single prefill pass across audio, video, text, and images to score valid parameters simultaneously.
  • Uses a two-stage attention routing mechanism and built-in lexical grammar to pull candidate values directly from internal embeddings, fine-tuned via LoRA.

AI coding agents generate more code, but not more software

Provides empirical, large-scale data on real-world engineering bottlenecks caused by AI coding agents.
  • Study analyzed 300 million work events across 700,000 engineers and 700 firms via Jellyfish data from 2021 to 2026.

  • Efficiency gains during generation are absorbed by downstream testing, review, and integration constraints.
