Qwen 3.8 27B is excellent, but it defaults to overthinking things

Covers practical local inference behavior and reasoning budget issues on the newly released Apache 2.0 Qwen 3.8 27B model.
  • Qwen 3.8 27B is an Apache 2.0 vision LLM that fits in a 17GB Q4_K_M quant and claims benchmarks exceeding Qwen 3.7-Plus.
  • Defaults to 'xhigh' reasoning effort, causing it to consume up to 22k+ reasoning tokens (21 minutes) on trivial prompts unless explicitly throttled.
  • Requires expanding local context limits to 262k tokens to prevent reasoning traces from exhausting default 8k context windows.

Qwen 3.8 27B is excellent, but it defaults to wildly overthinking things

Original post evaluating local deployment and over-reasoning dynamics in Alibaba's Qwen 3.8 27B open weights.
  • Qwen 3.8 27B ships with adjustable `reasoning_effort` (xhigh, medium, low) but defaults to xhigh, bloating latency substantially.
  • Turning off reasoning reduced a visual SVG prompt generation time from 21 minutes (22,276 reasoning tokens) to 137 seconds.
