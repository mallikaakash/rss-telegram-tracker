How Complex Systems Fail

This classic treatise by Richard Cook is essential foundational reading for understanding reliability, latent defects, and failure modes in complex distributed systems.
  • Complex systems inherently operate in degraded modes containing multiple latent flaws that are individually insufficient to trigger an outage.
  • Catastrophic failure requires the coincidence of multiple small, benign-seeming failures breaching defense-in-depth layers.
  • Post-incident root-cause attribution to single human error or proximate cause is an oversimplification of systemic failure dynamics.

What Is a Harness?

Provides a clear high-level architectural decomposition of AI agent harnesses, useful context for agentic tool use and LLM orchestration.
  • Defines the agent architecture as Agent = Model + Harness, where the harness provides runtime environment, execution state, and API abstractions.
  • Breaks down harness responsibilities into four pillars: system instructions, tool execution, the iterative agentic evaluation loop, and multi-model translation.
