Making Knowledge Distillation Cheap Enough to Run at Scale

Provides crucial systems techniques for cutting VRAM usage during LLM knowledge distillation to enable long-context training on single GPUs.
  • Caches teacher top-K logits offline to eliminate keeping teacher models loaded alongside student models in VRAM.
  • Introduces a fused chunked KL divergence loss to avoid materializing full vocabulary-by-sequence tensor matrices.
  • Enables long-context distillation recovery (32K+ context) directly on single-GPU hardware.

Meta is back with Muse Glimmer: local, agentic, multimodal, and open source

Delivers an essential architectural breakdown of Meta's new Muse Glimmer model, highlighting novel positional encoding schemes and inference optimizations.
  • Employs a hybrid attention scheme alternating 3 sliding window RoPE layers with 1 full attention layer using No Positional Embeddings (NoPE).
  • Features Gated Grouped-Query Attention with 16x KV-cache reduction and Q-K RMSNorm with explicit query scaling for logit stability.
  • Ships with an optional DFlash speculative decoding drafter tailored for local code generation in vLLM and llama.cpp.
