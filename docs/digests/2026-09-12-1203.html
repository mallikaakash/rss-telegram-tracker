So you want to use OpenRouter?

Directly impacts LLM inference serving, routing reliability, and downstream model behavior across backends.
  • OpenRouter's dynamic provider fallback introduces subtle discrepancies due to differing serving backends (vLLM, TGI), quantization, and flags.
  • Some fallback backends omit vision modality support or handle reasoning-effort parameters inconsistently.
  • Mitigate issues by pinning reliable backends using provider.only or inspecting available backends via the /endpoints API.
