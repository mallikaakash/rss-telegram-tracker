Branchless Rust: Making a Filter 4x Faster by Removing an If

High-quality low-level performance engineering post showing how CPU branch misprediction impacts hot-path data filtering.
  • At 50% selectivity, CPU branch predictors fail on conditional array filtering, creating massive pipeline stalls.
  • Replacing conditional `if` statements with branchless bitwise operations yields up to a 4x throughput speedup.
  • Shows that preallocating vector capacity doesn't solve performance bottlenecks when the primary constraint is hardware branch prediction.
