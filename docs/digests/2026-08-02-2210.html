How We Rebuilt Our Log Storage and Search Infrastructure for Scale

A solid infrastructure deep-dive detailing how Railway replaced Docker daemon polling with a scalable log aggregation system.
  • Shifted from pulling logs via Docker daemon polling every 2 seconds to forwarding logs to node-local Vector instances.
  • Uses Vector to tail local files for real-time streaming while batching logs to Google Cloud Storage for persistence.
  • Delivers real-time log streaming to the frontend via gRPC streams piped into GraphQL subscriptions.
