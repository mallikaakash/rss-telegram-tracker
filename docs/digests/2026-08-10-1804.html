COLDCARD's Random Numbers Weren't

A high-impact engineering security post-mortem demonstrating how a subtle C build macro bug led to predictable entropy and a $1.4M+ exploit.
  • The build check #ifndef HAS_RNG was bypassed because #define HAS_RNG 0 evaluated as defined, silently disabling hardware entropy.
  • Unreviewed commits went unnoticed for five years, eventually allowing attackers to sweep 1,432.48 BTC across 5,477 addresses.
  • Demonstrates critical war stories around build guards, code review discipline, and hardware security validation.
