A Preview of DuckDB v2.0

DuckDB v2.0 introduces major architectural upgrades including native client/server protocol and remote query pushdown relevant to backend data infrastructure.
  • Introduces native client/server mode via the 'quack' protocol and CONNECT syntax, shifting DuckDB from embedded-only to a networked server.
  • Includes remote pushdown optimization that ships raw SQL directly to PostgreSQL/MySQL instead of pulling full tables over the wire.
  • Adds asynchronous I/O, a new default storage format, a VARIANT data type, and a redesigned SQL parser.

AI-Generated GitHub Copilot "Autofix" Allowed Compromise of Snowflake's Jira

A practical CI/CD and AI security case study on how automated Copilot autofixes can silently introduce critical shell injection vulnerabilities.
