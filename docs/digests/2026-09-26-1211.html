Ollaya – Ollama for open-source, Jev-style decision models

Directly relevant to ML inference optimization and SLM architectures using single forward-pass classification instead of autoregressive decoding.
  • Serves decision models (Laya, Decider) using a single forward pass without token-by-token generation, dropping latency from >200ms to 8–10ms on an RTX 4090.
  • Extracts typed, calibrated probabilities directly from option-letter logits across choice, score, and boolean schemas.
  • Provides drop-in compatibility with TypeSafe's API and supports both encoder-based NLI and decoder-based (Qwen 3.5) classifiers.
