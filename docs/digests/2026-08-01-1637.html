A crucial production post-mortem detailing container memory isolation failure, swap exhaustion, and kernel soft-locks.
  • A single user workload bypassed memory limits, consuming over 95% of node host memory and triggering severe swap thrashing.
  • The host node entered an unrecoverable kernel soft-lock state, requiring a full node restart and a 30-minute image graph rebuild.
  • Underscores critical failure modes in container multi-tenancy, swap configuration, and cgroup enforcement under heavy load.
