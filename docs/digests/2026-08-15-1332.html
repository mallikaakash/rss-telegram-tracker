Show HN: ThoughtDAG – An editable context graph for LLM conversations

Provides an interesting DAG-based mental model and tool for visually inspecting, pruning, and managing LLM prompt context trees.
  • Models LLM conversational history as an explicit directed acyclic graph rather than a linear message array.
  • Allows arbitrary pruning and merging of context branches to reduce token usage and prevent prompt pollution.
  • Compiles graph traversals into exact ordered message payloads before hitting the model API.

Super Mario Derivations

A creative demonstration of Nix's lazy evaluation and content-addressed derivations applied to game state caching.
  • Leverages Nix lazy evaluation to represent infinite tree walks as Nix attribute paths.
  • Treats individual NES controller inputs and frames as isolated Nix derivations with savestates as inputs.
  • Demonstrates deterministic incremental execution graph caching using nixpkgs architecture.
