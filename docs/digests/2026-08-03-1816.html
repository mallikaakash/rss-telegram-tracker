Prevent cognitive debt by manually retyping LLM-generated code

Offers a practical developer workflow strategy to avoid cognitive debt and catch LLM hallucinations when using AI coding assistants.
  • Allowing AI agents to directly modify repository files creates cognitive debt and degrades developer mental models of complex codebases.
  • Forcing LLMs to output proposed changes in chat to be manually typed forces active code reading, catching subtle hallucinations and bad design choices.
  • Trades raw generation speed for better architectural familiarity and spatial awareness of the codebase.
