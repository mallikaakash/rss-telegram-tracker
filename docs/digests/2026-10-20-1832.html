Rebuilding LinkedIn's Tracking Infrastructure: Scaling, Migrating, and Hardening a High-Volume Event Pipeline

A classic high-scale infrastructure war story from LinkedIn on modernizing a mission-critical distributed event streaming system.
  • Processes hundreds of billions of events per day (millions per second peak) across hundreds of schemas for analytics and ML signals.
  • Migrated from legacy Java 8/Play REST services to modern Java and gRPC, requiring complete serialization rewrites rather than a simple transport swap.
  • Decoupled shared capacity pools into isolated resources to prevent bursty media and heavy observability payloads from starving critical engagement events.
Must readHugging Face Blog

MPS in PyTorch 2.15

Directly covers GPU performance engineering and inference acceleration, featuring major MoE kernel optimizations and FP8 quantization.
  • MoE decoding achieves 5–6.5x speedups (Qwen3.6-35B-A3B jumped from 9.4 to 61.3 tok/s on M3 Ultra) via native grouped GEMM, faster top-k routing, and eliminated GPU-CPU syncs.
  • Introduces native FP8 (`float8_e4m3fn`) storage and scaled matrix multiplication on Apple Silicon.
  • Optimized vocabulary softmax is ~8x faster and Wan2.2 video VAE decode peak memory dropped from 270 GiB down to 8 GiB by swapping MPSGraph for custom Metal kernels.

Presents an innovative formulation combining Quality-Diversity evolutionary search with LLMs for structured hypothesis exploration and recommendation.
  • QD-Rec pairs candidates with explanatory hypotheses using bandit selection to balance exploring unvisited options versus exploiting promising ones.
  • Uses mutation and crossover prompts with LLMs to generate new hypotheses, keeping diverse entries alive via niche-based local competition instead of global ranking.
  • Evaluated on M&A target discovery, customer targeting, and academic paper recommendations against zero-shot novelty baselines.

The Agentic Analytics Benchmark, round two: GPT-6, Claude Opus 5.5, Claude Sonnet 5.5

Provides empirical evaluation data on LLM agentic performance, SQL generation reliability, and cost-per-query over an OLAP engine.
  • Benchmark evaluates models over 201 analytical queries on ClickHouse with an agentic SQL tool-calling budget of 60 turns.
  • Claude Fable 5.1 retained top performance at 76.6% accuracy, while Claude Sonnet 5.5 saw the biggest jump (+6.5 points over Sonnet 5, zero budget timeouts at ~5 cents/question).
  • Newer GPT-6 family models scored in a tight 68.7–69.7% band, showing negligible improvement over GPT-5.5 on SQL analytics.
